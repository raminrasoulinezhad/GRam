# Status — paused 2026-08-01

## What works

The PoC core loop is built and its logic is fully covered by passing tests.

- **Catalog** — 873 exercises bundled from [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
  (public domain), regenerated by `npm run build:catalog`. Search by name, filter by muscle /
  equipment / category / level.
- **Plans** — create, rename, duplicate, delete; add/remove/reorder exercises; per-item set
  templates, rest interval, and recorded-value kind.
- **Session** — start from a plan or empty; add/remove exercises; add/remove sets; edit
  weight/reps/time/distance inline; record a set and un-record it; rest timer; finish (keeps only
  recorded sets) or discard.
- **Body** — front/back heatmap with a weekly-volume view and a recovery view, plus a per-muscle
  numeric breakdown.
- **History** — 7-day rollup, per-session cards, per-session detail, per-exercise history on the
  how-to page.

## Test state

`npm test` → **106 passing, 17 failing**.

- **106 passing** cover all app logic: catalog integrity and search, effective-set volume maths,
  window boundaries, the recovery decay curve, the muscle→body-slug map, formatting and unit
  conversion, and every store action including the full record/un-record loop.
- **17 failing** are all in `src/__tests__/session.screen.test.tsx`, and all fail for one
  tooling reason, not an app defect: `@testing-library/react-native` v14 replaced
  `react-test-renderer` (deprecated in React 19.2) with the new `test-renderer` package, and
  `render()` is not wiring up under the `jest-expo` preset — every assertion then fails with
  "`render` function has not been called".

  **Next step:** align the RTL v14 setup with jest-expo (likely a `setupFilesAfterEach` /
  preset composition change in `jest.config.js`), or pin RTL to v13 with a React 18 test
  renderer. The test file itself is written and does not need changing.

## Two real bugs the tests already caught and fixed

1. Nine upstream exercises (Clean and Press, Barbell Step Ups, …) listed a muscle as **both**
   primary and secondary, which credited 1.5 effective sets for one set and inflated the
   heatmap. `scripts/build-catalog.mjs` now strips the duplicate; primary wins.
2. Plank, Side Bridge and 6 other isometric holds were being given a **weight × reps** set
   shape because the dataset files them under "strength". They are now keyed off
   `force: "static"` → timed sets.
